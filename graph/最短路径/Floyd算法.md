### Floyd算法：全源最短路径问题

**Floyd算法**（也称为**Floyd-Warshall算法**）用于解决**加权图中所有节点对之间的最短路径问题**。该算法适用于**有向图**和**无向图**，并且能够处理**非负权重**的图。在某些情况下，它还可以处理具有**非正权重**的图，但不能处理具有**负权重环**的图，因为负权重环会导致无限短的路径。

#### 问题定义

给定一个图，包含 `V` 个顶点，目标是找到每对顶点 `i` 和 `j` 之间的最短路径。我们使用一个**权重矩阵** `W` 来表示图：
- `W[i][j]` 表示从顶点 `i` 到顶点 `j` 的边的权重。
- 如果顶点 `i` 到顶点 `j` 没有直接边，则设置 `W[i][j] = ∞`（表示无穷大）。

Floyd算法会逐步构建一个**距离矩阵** `D`，其中 `D[i][j]` 表示从顶点 `i` 到顶点 `j` 的最短路径长度。

### 核心思想

Floyd算法的核心思想是，对于任意一对顶点 `i` 和 `j`，从 `i` 到 `j` 的最短路径要么是：
1. 不经过某个中间顶点 `k` 的已知最短路径；
2. 经过某个中间顶点 `k`，即先从 `i` 到 `k`，再从 `k` 到 `j` 的路径。

因此，Floyd算法通过逐步考虑每个顶点作为可能的“中间节点”，来更新每对顶点之间的最短路径。

#### 递推关系

距离矩阵 `D` 是逐步构建的，遵循以下递推关系：

1. 初始时，令 `D^0[i][j] = W[i][j]`，即初始的距离等于图中的边权重（如果不存在边，则为无穷大）。
   
2. 对于每个 `k = 1, 2, ..., V`（`V` 是顶点数量），更新距离矩阵 `D`，递推公式如下：
   
$$
D^k[i][j] = \min(D^{k-1}[i][j], D^{k-1}[i][k] + D^{k-1}[k][j])
$$

   该公式表示，当考虑顶点 `k` 作为中间节点时，从 `i` 到 `j` 的最短路径，要么是之前的最短路径 `D[i][j]`，要么是通过 `k` 的路径，即 `D[i][k] + D[k][j]`。

### Floyd算法的伪代码

根据上述递推关系，Floyd算法的伪代码如下：

```plaintext
function Floyd(W[1..n, 1..n])
    D ← W  // 用权重矩阵 W 初始化距离矩阵 D
    for k ← 1 to n do
        for i ← 1 to n do
            for j ← 1 to n do
                D[i, j] ← min(D[i, j], D[i, k] + D[k, j])
    return D
```
c语言代码如下：

```c
#include <stdio.h>

#define V 4  // 顶点数量
#define INF 99999  // 表示无穷大的值

// Floyd算法函数：计算所有顶点对的最短路径
void floydWarshall(int graph[V][V]) {
    int dist[V][V], i, j, k;

    // 初始化距离矩阵，复制邻接矩阵中的值
    for (i = 0; i < V; i++) {
        for (j = 0; j < V; j++) {
            dist[i][j] = graph[i][j];
        }
    }

    // Floyd-Warshall算法的核心部分
    for (k = 0; k < V; k++) {
        for (i = 0; i < V; i++) {
            for (j = 0; j < V; j++) {
                // 通过顶点 k 更新从顶点 i 到顶点 j 的最短路径
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }

    // 打印最终的最短路径距离矩阵
    printf("最短路径矩阵：\n");
    for (i = 0; i < V; i++) {
        for (j = 0; j < V; j++) {
            if (dist[i][j] == INF)
                printf("%7s", "INF");
            else
                printf("%7d", dist[i][j]);
        }
        printf("\n");
    }
}

int main() {
    // 图的邻接矩阵表示（有权重的图，INF表示没有直接路径）
    int graph[V][V] = {
        {0, 3, INF, 7},
        {8, 0, 2, INF},
        {5, INF, 0, 1},
        {2, INF, INF, 0}
    };

    // 调用Floyd-Warshall算法
    floydWarshall(graph);

    return 0;
}
```

- **初始化**：我们将距离矩阵 `D` 初始化为权重矩阵 `W` 的副本。初始时，`D[i][j]` 代表顶点 `i` 和 `j` 之间的直接距离。
- **主循环**：对于每个顶点 `k`，对每对顶点 `(i, j)` 进行检查，更新 `D[i][j]`，看看是否通过顶点 `k` 可以获得更短的路径。

### 示例

假设我们有一个简单的图，有 4 个顶点，其初始权重矩阵 `W` 如下：

```plaintext
W = [
    [0, 3, ∞, 7],
    [8, 0, 2, ∞],
    [5, ∞, 0, 1],
    [2, ∞, ∞, 0]
]
```

- 顶点 1 与顶点 2 之间的边权重为 3，顶点 1 与顶点 4 之间的边权重为 7。
- 顶点 2 与顶点 1 之间的边权重为 8，顶点 2 与顶点 3 之间的边权重为 2。
- 顶点 3 与顶点 1 之间的边权重为 5，顶点 3 与顶点 4 之间的边权重为 1。
- 顶点 4 与顶点 1 之间的边权重为 2。

#### 逐步计算

1. **初始距离矩阵**：`D^0 = W`。

2. **第1次迭代 (`k = 1`)**：考虑顶点1作为中间节点，更新所有顶点对的最短路径。

$$
   D^1[i][j] = \min(D^0[i][j], D^0[i][1] + D^0[1][j])
$$

   通过顶点 1，检查从顶点 `i` 到 `j` 是否可以获得更短的路径。

3. **第2次迭代 (`k = 2`)**：考虑顶点2作为中间节点，继续更新所有顶点对的最短路径。

$$
   D^2[i][j] = \min(D^1[i][j], D^1[i][2] + D^1[2][j])
$$

4. **第3次迭代 (`k = 3`)**：考虑顶点3作为中间节点。

$$
   D^3[i][j] = \min(D^2[i][j], D^2[i][3] + D^2[3][j])
$$

5. **第4次迭代 (`k = 4`)**：考虑顶点4作为中间节点。

$$
   D^4[i][j] = \min(D^3[i][j], D^3[i][4] + D^3[4][j])
$$

最后，矩阵 `D` 将包含所有顶点对之间的最短路径。

### 时间复杂度

Floyd算法的时间复杂度为 **O(V³)**，其中 `V` 是图中的顶点数。这个复杂度来自于三个嵌套的循环，每个循环都遍历顶点。

### 与Dijkstra算法的比较

- **Floyd算法**对于稠密图（即边的数量接近顶点数平方）更简单和高效，因为它直接使用矩阵来表示图，并且可以一次性计算所有顶点对之间的最短路径。
- **Dijkstra算法**适用于稀疏图，尤其是结合优先队列（如Fibonacci堆）时，可以将复杂度降低到 **O(V² log V)**。Dijkstra需要对每个顶点运行一次，因此适用于**稀疏图**（即边数远少于顶点数平方）。

### 为什么使用Floyd算法？

1. **实现简单**：算法的实现非常直接，只需要使用一个矩阵来表示图。
2. **一次计算所有最短路径**：Floyd算法可以在一次运行中找到所有顶点对的最短路径，而Dijkstra算法需要对每个顶点运行 `V` 次。
3. **适用于稠密图**：对于稠密图，Floyd算法的效率非常高，因为稠密图的边数接近顶点数的平方，直接使用矩阵表示图是合适的。

### 总结

Floyd算法是一种计算所有顶点对之间最短路径的有效方法，尤其适用于稠密图。虽然时间复杂度为 O(V³)，但其实现简单，适合全源最短路径问题。对于稀疏图，可以使用Dijkstra算法，它在结合优先队列时能提供更好的性能。
